# Telegram-бот записи на услугу

Бот для приёма записей клиентов: барбершоп, маникюр, массаж, репетиторство —
подходит под любую услугу по времени. Клиент выбирает услугу → дату → время →
оставляет имя и телефон → администратор получает уведомление в Telegram.

## Возможности

- Пошаговая запись через inline-кнопки (без ручного ввода дат/времени)
- Занятые слоты автоматически скрываются из списка
- Уведомление администратору о каждой новой записи
- Команда `/my_bookings` — клиент видит свои записи
- Хранение в SQLite — не нужна внешняя база данных
- Список услуг и рабочие часы настраиваются в одном месте (`config.py`)

## Стек

Python 3.11+, aiogram 3, SQLite

## Запуск

1. Установить зависимости:
   ```
   pip install -r requirements.txt
   ```
2. Скопировать `.env.example` в `.env` и вписать токен бота:
   ```
   cp .env.example .env
   ```
3. Получить токен: написать [@BotFather](https://t.me/BotFather) → `/newbot` →
   скопировать выданный токен в `.env`.
4. (Опционально) узнать свой `ADMIN_CHAT_ID` — написать
   [@userinfobot](https://t.me/userinfobot), он пришлёт ваш ID.
5. Запустить бота:
   ```
   python bot.py
   ```

## Настройка под конкретный бизнес

Все услуги и часы работы — в `config.py`:

```python
SERVICES = ["Стрижка", "Маникюр", "Массаж"]
WORK_HOURS = [10, 11, 12, 13, 14, 15, 16, 17, 18]
```

Меняете список — бот сразу подстраивается под новые услуги/часы, код трогать
не нужно.

## Как это развернуть, чтобы бот работал круглосуточно

Пока запущен `python bot.py` на компьютере — бот отвечает. Чтобы он работал
24/7, нужен сервер (VPS). Варианты: Timeweb, Beget, Selectel — от 200–300 ₽/мес.
На сервере команды те же самые (шаги 1–5 выше), плюс процесс лучше держать
через `systemd` или `screen`/`tmux`, чтобы он не останавливался при закрытии
терминала.
